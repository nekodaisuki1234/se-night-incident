# SE激詰めシミュレーター — 夜間バッチ障害編

金融系SESの中堅SEとして、夜間バッチの復旧と顧客・社内対応を同時に進めるスマートフォン向けブラウザゲーム。

## 現在：試作 v0.4

連携ファイル未着の1シナリオを、開始から復旧報告まで遊べます。状況に応じた3つの選択肢によるチャット操作報告、社内チャット、承認と無断実行、顧客メールと文字の電話、別ジョブ誤停止による追加障害、遅延時の追及、結果・対応履歴を実装しました。

AIは使っていません。自由入力はなく、各段階の3択を選ぶだけで最後まで遊べます。原因ランダム化・容量不足・DBロックは次の段階です。

## 実行・検証

ビルド不要。HTTPで `dist` を配信してください。VercelならFrameworkはOther、Build Commandはなし、Output Directoryは `dist`。

`npm test` で正常復旧、無断実行、誤停止、承認範囲、検証不足、遅延など16個のテストを実行できます。

[試作の範囲と検証](PROTOTYPE.md) / [初版設計](docs/design.md)

## 制作順序

1. 要件・シナリオ・画面設計：完了
2. スマホ画面と1シナリオの試作：実装済み、実機の見た目・音を確認する段階
3. 3種類のランダム障害と会話の充実：次の段階
4. スマホ操作とゲームバランスの調整
5. 一般公開先の設定

コマンドとSQLは架空の環境だけを操作します。リポジトリの公開範囲とゲームの公開範囲は別々に管理します。


画面はTeams風の配色・会話レイアウトに変更。リーダー「鬼塚」が毎回の選択と電話対応に内容を踏まえた指摘を返します。

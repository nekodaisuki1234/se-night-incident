# SE激詰めシミュレーター — 夜間バッチ障害編

金融系SESの中堅SEとして、夜間バッチ障害の復旧と顧客・社内対応を同時に進める、スマートフォン向けブラウザゲーム。

現在は設計段階です。ゲーム本体の実装・公開はまだ行っていません。

## 初版の仕様

- 一般公開を目標に、スマートフォンの縦画面を優先する。
- Linuxコマンド・SQLは候補ボタンと手入力の両方を提供する。
- 障害原因はプレイごとにランダムに変わる。
- 社内チャットと顧客メール・電話を分ける。電話は着信音と文字・返答選択で表現する。
- リーダーへの確認が基本。無断操作も可能だが、失敗時は障害拡大と強い追及が発生する。
- 遅い返信・操作で段階的に追い込まれる。全体の常時カウントダウンは中心にしない。
- 初版はAIを使わず、将来は会話部分をAIに差し替えられる構成にする。
- コマンドとSQLはゲーム内の架空環境を操作する。実際のサーバーには接続しない。

## 設計と制作順序

[初版設計](docs/design.md) に、確定事項、画面構成、障害案、採点と検証方針を記載しています。

1. 要件・シナリオ・画面設計（現在）
2. スマホ画面と操作・会話の試作
3. ランダム障害と承認・誤操作・複数エンドの実装
4. スマホでの操作確認とゲームバランス調整
5. 一般公開先の設定と公開

公開先、実装フレームワーク、具体的な猶予時間は試作で決定します。
